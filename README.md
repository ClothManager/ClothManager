## Descripción
ClothManager es un sistema de gestión integral para el sector textil. Este repositorio contiene la documentación, el levantamiento de historias de usuario, el diseño de APIs y la planificación del proyecto.

## Contenido
* `Parcial_Dos_Web_Service.pdf`: Documento consolidado del Parcial #2.
* `Matriz_APIs.xlsx`: Inventario y diseño de las 108 APIs (internas y externas).
